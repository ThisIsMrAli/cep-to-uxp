Why this matters now

Adobe has already published the CEP sunset. Teams with shipping panels need a path that does not start from an empty Spectrum file. This skill is that path: an agent reads the CEP project, asks which UI to build, and writes a UXP plugin beside it. The CEP project is not modified.

What the agent is required to do

It is a procedure, not a one-shot copy. Cursor, Claude, Codex, and the other supported agents load the same folder.

  1. Refresh Adobe’s docs on this run. Known issues, unsupported HTML, and the supported CSS list are saved and followed. A new app id stops the port. None is invented.
  2. Read the source, not only the built snapshot. Then stop and ask: UI, design, and host.
  3. Clone the screens into pure UXP. Native HTML, or a bolt React, Vue, or Svelte port. Same regions and copy. A missing label is not finished.
  4. Move host work out of the page. Photoshop, InDesign, Premiere, and Media Encoder APIs run in the host. JSX is never executed.
  5. Load the parent folder in the UXP Developer Tool. A checker that prints OK does not mean a click survives.

Pure UXP first

The agent recommends the first matching pure path. WebView is offered last, and only written if the user chooses it.

ModeWhenResult
native A small static or vanilla page. The HTML is the UXP document. No WebView.
bolt-react React and similar component stacks. A pure UXP document plus the CEP screens to clone. No WebView folder.
bolt-vue / bolt-svelte Vue or Svelte. The matching bolt starter, still a UXP document.
retarget / keep Last resort. The old page must stay. That page loads in a WebView. Host calls still move to UXP.

Live limits

Before it writes files, the skill downloads Adobe’s current known-issues page, the unsupported HTML lists, and the supported CSS index. It follows the limits that are on those pages today.

What it will not pretend

  • The UXP document is not the CEP browser. CSS grid, gap, text-transform, the font shorthand, and CSS animations are not in Adobe’s supported set.
  • A compat script loads first on a pure UXP port, for gaps real panels hit: observers, missing DOM constructors, and currentColor.
  • UXP cannot run JSX. The control stays, and the handler returns the old error.
  • Servers, sockets, and native addons are reported. They are not rewritten into JavaScript.
  • localStorage on a plugin page does not keep CEP settings. The user enters them again.

Install

Node.js 18 or newer. In Cursor, Claude Code, or Codex:

npx skills add ThisIsMrAli/cep-to-uxp --skill cep-to-uxp -a cursor

Then run /cep-to-uxp on the folder that contains CSXS/manifest.xml. The agent will ask before it converts.
