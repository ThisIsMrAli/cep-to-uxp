CEP panels, carried into UXP.

An agent skill for Photoshop, InDesign, Premiere Pro, and Media Encoder. It always asks which path to take. Native UXP or a Spectrum starter first. WebView last. ExtendScript and Node move to the host.

Install the skill See the modes

Page

React, Vue, Svelte, Angular, Solid, Lit, Alpine, TypeScript, or plain JavaScript. The component tree is not redrawn in Spectrum.

Bridge

evalScript crosses postMessage. The handler returns a string. A throw is delivered as text, not hidden.

Host

Photoshop, InDesign, and Premiere APIs run in the UXP shell. JSXBIN is copied and never executed.

What the agent is required to do

The skill is a procedure, not a one-shot copy. Cursor, Claude, Codex, Gemini, Windsurf, Continue, OpenCode, and GitHub Copilot can all load the same folder.

  1. Confirm CSXS/manifest.xml. Stop if the folder is already a UXP plugin.
  2. Refresh Adobe’s public UXP docs. If a documented app id is missing from the skill, stop. Do not invent one.
  3. Scan source, not only the minified bundle. build/ and dist/ are snapshots.
  4. Ask which UI, design, and host. Suggest native UXP or bolt first. Do not pick automatically.
  5. Write a new folder. Leave the CEP project untouched.
  6. Validate until the checker prints OK.
  7. Tell every uncovered line in MIGRATION.md before calling the port finished.
  8. When RETARGET.md exists, move readable host calls, rebuild, and load that bundle.

UI modes

Pass one with --ui after the user answers. Spectrum chrome on the shell is --design spectrum. --design preserve adds no new frame. Native and bolt are the suggested path. WebView is last resort.

ModeUse it whenResult
native Suggested for a small static or vanilla page. No WebView. The CEP HTML is the UXP document. A leftover new CSInterface() throws.
bolt-react Suggested for React and similar stacks. Pure UXP document plus bolt/cep-src/ to clone. No WebView folder. Dependencies are not installed.
bolt-vue Suggested for Vue. A Vue starter in bolt/.
bolt-svelte Suggested for Svelte. A Svelte starter in bolt/.
retarget Last resort: keep the existing UI. The current UI stays in the WebView. ui-src/ and RETARGET.md separate ExtendScript and Node onto the host.
keep Last resort: built panel only. The page is copied into the WebView. Calls that still hit CEP or Node stay dead until they are moved.

Strategies the scanner reports

webview

The usual result. A UXP shell hosts the existing page. The shim replaces CSInterface.js.

hybrid

The same shell. child_process, sockets, or a .node file were found. Those calls are listed. A native addon is not built.

native

No framework, Node, or CEP bridge was found, so the HTML can be the UXP document.

blocked

Illustrator, After Effects, or any host with no documented UXP panel id. A report is written. No manifest app id is invented.

UI stacks

Plain JavaScript, TypeScript, React, Preact, Vue, Nuxt, Svelte, Angular, Solid, Lit, and Alpine. Browser libraries such as jQuery, MUI, and Bootstrap stay in the page that already uses them. The converter recognizes them from imports and package.json. It does not compile. Retarget names the project’s build script so the agent can.

What it will not pretend

  • UXP cannot run JSX or JSXBIN. The shim only transports the script string.
  • path.join and a throwing fs keep the first mount alive. They are not a filesystem.
  • In-memory localStorage is used only when the real one throws. Those values are not saved.
  • A Node preload is removed from the page. Loading it throws and blanks the panel.
  • Servers, sockets, and .node addons are reported. They are not rewritten into JavaScript.

Install

Node.js 18 or newer. From the skills CLI, for Cursor, Claude Code, or Codex:

npx skills add <owner>/cep-to-uxp --skill cep-to-uxp -a cursor

In Cursor, type /cep-to-uxp and give the folder that contains CSXS/manifest.xml.

node .claude/skills/cep-to-uxp/scripts/convert.mjs \
  --input /path/to/cep-extension \
  --out /path/to/extension-uxp \
  --force --ui bolt-react --design spectrum --host PS
